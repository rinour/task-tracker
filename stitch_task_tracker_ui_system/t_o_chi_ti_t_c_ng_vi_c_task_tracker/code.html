Chi tiết thực hiện kỹ thuật:

  • Tái cấu trúc Dockerfile áp dụng kỹ thuật multi-stage build để cache các gói dependency của Node.js và Go.
  • Thiết lập cơ chế pull/push Docker layer cache trực tiếp từ AWS ECR thay vì tải lại từ đầu mỗi build job.
  • Phân tách và cấu hình song song hóa các runner cho bước Unit Test, E2E Cypress và Lint check.
